## 组成

| 文件 | 说明 |
|------|------|
| `httplogin.cpp` | 主程序：判断网络状态，掉线时自动登录（Windows GUI 子系统，无窗口）|
| `campus_ctl.cpp` | 控制台工具：1 上线 / 2 下线 / 3 重新登录 / 4 退出 |
| `campus_keepalive.cpp` | 保活进程：每 20 秒探测一次网关，由 `httplogin` 登录成功后拉起，无窗口 |
| `install_autostart.bat` | 安装：关 NCSI 探测 + 创建登录触发的计划任务 + 桌面快捷方式 |
| `uninstall_autostart.bat` | 卸载：删任务 + 恢复 NCSI |

## 工作流程

直接调门户的 HTTP 接口，不模拟点击网页。

1. **前置闸门**：读当前联网网卡类型
   - 有线（`IanaInterfaceType = 6`）→ 继续
   - WiFi（`71`）且 SSID 完全等于 `GDPT-Student` → 继续
   - WiFi 但 SSID 不匹配 → 直接退出，不登录
   - 读不到 SSID / 判断异常 → fail-open，照常登录（宁可多登一次，不能漏登）
2. 读同目录 `auth.txt`（第 1 行账号、第 2 行密码），或命令行参数
3. 判断网络级别（WinRT `GetNetworkConnectivityLevel`）
4. 快速探针：`9.9.9.9` 的 TCP 连接
   - 不可达 → 可能是已联网，用 `connect.rom.miui.com` 复检；通则退出
   - 可达 → 被网关劫持，进入登录流程
5. 依次请求触发地址（`9.9.9.9` → `223.5.5.5` → 小米检测页）拿门户地址
6. 从返回内容提取 `location.href` → 门户 URL + queryString
7. 门户地址自适应（`ExtractOrigin`），兜底 `10.110.141.3`
8. POST `InterFace.do?method=login`
9. 结果判定
   - `result = success` → 登录成功
   - 门户提示「已在线」→ 按成功处理（会话还有效，绝不去下线）
   - 门户提示「设备未注册」→ **会话僵死**（长时间无心跳被踢但状态残留）：先调 `logout` 清掉旧会话，再重登一次
   - 其它 → 登录失败
10. 成功（含已在线）后拉起 `campus_keepalive.exe`

登录成功全程只需 2 次 HTTP 请求，1~2 秒完成。

## 退出码（httplogin.exe）

`campus_ctl.exe` 按这套码判断上线是否成功。

| 码 | 含义 |
|----|------|
| 0 | 登录成功 / 门户提示已在线 / 网络正常无需登录 / 不是本校网络直接跳过 |
| 1 | 没找到账号密码 |
| 2 | 看门狗 70 秒超时 |
| 3 | 登录失败（账号密码不对，或门户拒绝） |
| 4 | 未能确认网络状态，放弃 |

`campus_ctl.exe` 自身退出码：`0` 成功 / `1` 用法错误 / `2` 上线失败 / `3` 下线失败 / `4` 重登失败 / `5` 用户取消。

## 保活进程

`campus_keepalive.exe` 由 `httplogin.exe` 在登录成功后用 `CreateProcessW` 拉起：

- 每 20 秒 ping 网关 `10.160.0.1`（超时 1000 ms）
- 失败则再 ping 公网 `223.5.5.5`，并把结果写进日志
- 命名互斥量保证单实例；互斥量冲突时退避重试（吃掉「上一个刚被杀、内核还没拆完」的窗口）
- 日志 `keepalive_log.txt`，每次真正启动清空

## 关键实现细节

- **无窗口**：PE 子系统设为 Windows GUI，失败时才 `AllocConsole` 弹提示；若已继承控制台，则直接写到该控制台，不再静默失败
- **便携**：`auth.txt` 和日志都定位到 exe 自身目录（`GetModuleFileNameW`），整个文件夹可搬走
- **崩溃可见**：`SetUnhandledExceptionFilter` 把异常码/地址写进日志；崩在日志函数内部时直接放弃写，避免二次崩溃
- **超时兜底**：独立 watchdog 线程 70 秒强制结束；已有结论（成功或失败已定）后不再改写退出码
- **日志线程安全**：`CRITICAL_SECTION` 保护，看门狗线程与主线程不会同时碰文件句柄

## 使用

1. 账号密码写进 `auth.txt`（第 1 行学号，第 2 行密码），与 exe 放在同一目录
2. 右键 `安装校园网自动登录.bat` → 以管理员身份运行
3. 之后每次登录 Windows 自动认证

## 注意事项

- 跑 bat 时杀毒软件可能拦截（创建计划任务/快捷方式），选允许
- 门户地址代码里有兜底 `10.110.141.3`，换校区可能要调整
- WiFi 闸门里的 `GDPT-Student` 按校名不同要改；不分发到外校时保持原样
- **分发时 `auth.txt` 必须是空模板**，不要带上自己的账号密码

## 环境实测数据（某高校有线校园网）

| 地址 | 联网时 | 掉线时 |
|------|--------|--------|
| `9.9.9.9` | http=000（4 秒超时）| http=200 + JS 跳转（0.01 秒）**唯一可用探针** |
| `223.5.5.5` | http=404 | http=200 —— 两种状态都可达，**不能当探针** |
| `114.114.114.114` | http=000 | http=000 —— 无信息 |
| `connect.rom.miui.com` | http=200 | http=200 —— 用作「探针不通时」的复检 |

结论：探针要选「掉线时被劫持、联网时不通」的地址；「联网时响应快」是错误的判断标准。
